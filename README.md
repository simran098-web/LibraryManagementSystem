Library Management System

About the Project

A console-based Library Management System developed using C++ and Object-Oriented Programming (OOP) concepts. It helps manage library operations in a simple, efficient, and organized way.

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling

Features

- Add new books to the library.
- Display all available books.
- Search books by ID or title.
- Delete book records.
- Add and manage student/member details.
- Display student records.
- Search students by their details.
- Issue books to students.
- Return issued books.
- Check book availability.
- Menu-driven interface for easy navigation.

OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Member Functions
- Data Handling
